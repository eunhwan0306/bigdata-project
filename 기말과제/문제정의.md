# 프로젝트 문제정의

## 1. 선택한 데이터
- 이름 / 출처(URL) / 라이선스:
고속도로 돌발상황 알림 정보 / 국토교통부 공공데이터포털 (data.go.kr) / 공공누리1유형
교통사고현황 마스터 데이터 / 한국도로공사 공공데이터포털 / 공공누리 1유형
종관기상관측(ASOS) 시간별 자료 / 기상청 기상자료개방포털 (data.kma.go.kr) / 기상청 공공데이터 이용약관

크기(행, 열) / 형식:
돌발상황: 실시간 스트림, JSON (공지일시·노선명·사고유형·통제차로수 등 약 15열)
교통사고 이력: 약 10만 건 이상, CSV (노선별·연도별 사고 건수·지연시간 등)
기상 데이터: 시간별 CSV (강수량·적설량·시정거리·기온 등 약 20열)
어떻게 받았나: Open API(돌발상황·ASOS), 다운로드(교통사고 이력 CSV)

## 2. 풀고 싶은 문제
한 문장으로: 고속도로 돌발상황·기상·과거 사고 이력 데이터로 특정 노선·시간대의 연쇄 정체 발생 위험도를 사전에 예측하고 싶다.

예측/분류 대상(target): 있음 — 노선별 구간의 정체 위험 등급 (예: 저·중·고 3단계 분류, 또는 정체 발생 확률 0~1 회귀)

## 3. 만들 서비스(완성 모습)
사용자가 입력 → 출발 노선(고속도로명), 출발 예정 시각, 현재 기상 조건(강수 여부 등)을 입력하면

→ 해당 노선의 구간별 실시간 위험도 지도 + 연쇄 정체 발생 확률 및 경고 메시지를 보여주는 Streamlit 웹앱

사용할 기술: ML (Random Forest / XGBoost 기반 분류 모델) + Open API 실시간 데이터 파이프라인

## 4. 예상 난관 1가지
API 데이터 불안정성 및 결측 처리: 국토교통부 돌발상황 API는 실시간 특성상 간헐적 응답 지연·누락·형식 변경이 발생할 수 있으며, 기상 데이터와의 시간 단위 매핑(예: 사고 발생 시각 ↔ 가장 근접한 ASOS 관측 시각) 과정에서 시간 정합성 불일치로 인한 대규모 결측이 생길 수 있습니다. 이를 해결하기 위해 API 호출 재시도 로직과 시간 보간(interpolation) 전략을 사전에 설계해야 합니다.
