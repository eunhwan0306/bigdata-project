# 프로젝트 문제정의

## 1. 선택한 데이터
- 이름 / 출처(URL) / 라이선스:
고속도로 돌발상황 알림 정보 / 국토교통부 공공데이터포털 (data.go.kr) / 공공누리1유형
교통사고현황 마스터 데이터 / 한국도로공사 공공데이터포털 / 공공누리 1유형
종관기상관측(ASOS) 시간별 자료 / 기상청 기상자료개방포털 (data.kma.go.kr) / 기상청 공공데이터 이용약관

크기(행, 열) / 형식:
돌발상황: 실시간 스트림, JSON (공지일시·노선명·사고유형·통제차로수 등 약 15열)
교통사고 이력: 약 10만 건 이상, CSV (노선별·연도별 사고 건수·지연시간 등)
기상 데이터: 시간별 CSV (강수량·적설량·시정거리·기온 등 약 20열)
어떻게 받았나: Open API(돌발상황·ASOS), 다운로드(교통사고 이력 CSV)

## 2. 풀고 싶은 문제
한 문장으로: 고속도로 돌발상황·기상·과거 사고 이력 데이터로 특정 노선·시간대의 연쇄 정체 발생 위험도를 사전에 예측하고 싶다.

예측/분류 대상(target): 있음 — 노선별 구간의 정체 위험 등급 (저·중·고 3단계 분류)

### 타깃 라벨링 방법 (혼합 방식 채택)

세 가지 방법을 검토한 뒤, 실용성과 데이터 가용성을 고려하여 **혼합 방식**을 채택한다.

| 방법 | 방식 | 장단점 |
|------|------|--------|
| 사고 이력 기반 | 과거 사고 데이터(노선·연도별 사고건수·지연시간)로 등급 산정 | 데이터 풍부, 실시간성 낮음 |
| 돌발상황 기반 | 실시간 돌발상황 API의 사고·통제차로수로 위험도 산정 | 실시간성 높음, 돌발상황만 반영 |
| **혼합 방식** (채택) | 과거 이력 위험도 + 실시간 요인 + 기상 가중치 결합 | 가장 실용적, 복잡도 관리 가능 |

**혼합 방식 산정 공식:**

```
이력_위험도 = 0.6 × (노선_사고건수 / 전체최대) + 0.4 × (평균지연_분 / 전체최대)
실시간_점수 = 통제차로수 × 기상가중치 × 이력_위험도
최종_위험도  = 0.6 × 이력_위험도 + 0.4 × 실시간_점수
등급 분류 : 0.00~0.35 → 저위험(0) / 0.35~0.65 → 중위험(1) / 0.65 이상 → 고위험(2)
```

이 방식은 과거 이력으로 노선별 기준 위험도를 먼저 확정한 뒤, 실시간 돌발상황·기상으로 보정한다.

## 3. 만들 서비스(완성 모습)
사용자가 입력 → 출발 노선(고속도로명), 출발 예정 시각, 현재 기상 조건(강수 여부 등)을 입력하면

→ 해당 노선의 구간별 실시간 위험도 지도 + 연쇄 정체 발생 확률 및 경고 메시지를 보여주는 Streamlit 웹앱

사용할 기술: ML (Random Forest — class_weight로 고위험 재현율 강화) + Open API 실시간 데이터 파이프라인

## 4. 예상 난관 1가지 (및 해결 전략)
API 데이터 불안정성 및 결측 처리: 국토교통부 돌발상황 API는 실시간 특성상 간헐적 응답 지연·누락·형식 변경이 발생할 수 있으며, 기상 데이터와의 시간 단위 매핑(예: 사고 발생 시각 ↔ 가장 근접한 ASOS 관측 시각) 과정에서 시간 정합성 불일치로 인한 대규모 결측이 생길 수 있습니다.

| 문제 | 해결 방법 |
|------|-----------|
| API 응답 지연·실패 | 재시도 로직 (retry 3회), timeout 5초 설정 |
| 데이터 누락 | 통제차로수→0, 기상상태→맑음, 지속시간→중앙값 대체 |
| 시간 정합성 | `merge_asof(direction="nearest", tolerance=90min)` 로 가장 근접한 ASOS 관측 매핑 |
| 형식 변경 | 컬럼명 rename 딕셔너리 집중 관리, 필수 컬럼 누락 시 fallback |

## 5. 모델 및 평가 전략

- **모델**: Random Forest Classifier (`class_weight={저:1.0, 중:1.5, 고:3.0}`)
  - 트리 기반 모델은 노선·시간대·사고유형·기상 등 비선형 관계에 유리
  - class_weight 으로 고위험 과소탐지(False Negative) 억제

- **주요 평가 지표**: 고위험 **재현율(Recall)**
  - 위험을 놓치는 False Negative 가 오경보(False Positive) 보다 훨씬 큰 피해 유발
  - Accuracy 외 정밀도·재현율·F1(클래스별)을 함께 보고

- **보조 지표**: Precision, F1-macro, 혼동 행렬(고위험 행 집중 확인)
